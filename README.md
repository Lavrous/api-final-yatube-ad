# Yatube API (api-final-yatube-ad)

## Описание
Yatube API — это REST API для социальной сети Yatube. Проект позволяет пользователям публиковать свои посты, оставлять комментарии, подписываться на других авторов и просматривать тематические сообщества (группы). 
В проекте реализована система аутентификации по JWT-токенам. Неавторизованные пользователи имеют доступ к API только на чтение.

## Технологии
- Python 3.9+
- Django 3.2+
- Django REST Framework (DRF)
- Djoser (для работы с JWT-токенами)
- SQLite3
